# Armstrong Numbers in a Given Range Using C

## Description
This program displays all Armstrong numbers between 1 and a user-provided limit using loops and conditional statements.

## Concepts Used
- `for`, `while`, and `do-while` loops
- Conditional statements
- Modulus and division operators
- Digit counting
- Power calculation

## How to Run
```bash
gcc armstrong_range.c -o armstrong_range.exe
./armstrong_range.exe
```

## Language
C
